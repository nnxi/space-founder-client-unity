# Space Founder

> "Welcome to your own space!" 
> 끝없이 펼쳐진 미지의 우주로 여러분을 초대합니다.

Space Founder는 웹 브라우저에서 곧바로 즐길 수 있는 **실시간 대규모 우주 탐험 시뮬레이션**입니다. 
자신만의 행성을 개척하고, 끝없는 우주를 유영하며 다른 탐험가들의 행성을 발견해 보세요. 우주의 크기는 무한하며, 여러분의 발길이 닿는 모든 곳이 곧 새로운 세계가 됩니다.

---

## What You Can Do
    
* **나만의 행성 가꾸기:** 나만의 궤도와 특성을 가진 행성을 관리하고 우주에 기록하세요.
* **광활한 우주 탐험:** 정해진 맵은 없습니다. 자신의 행성과 함께 유영하며 미지의 천체들을 발견해 보세요.
* **실시간 멀티플레이:** 같은 우주 공간을 공유하는 다른 탐험가들과 실시간으로 조우하고 정보를 살펴볼 수 있습니다.

---

## Tech Stack

쾌적한 브라우저 환경에서 압도적인 스케일의 우주를 구현하기 위해 아래의 기술 스택을 사용했습니다.

* **Client:** Unity 3D (WebGL)
* **Server:** Node.js (Bare-metal), Socket.IO
* **Database & Auth:** Supabase

## Behind the Simulation (Core Technologies)

Space Founder는 단순한 웹 게임을 넘어, 여러 최적화 기법을 도입하여 브라우저 환경의 한계를 극복했습니다.

### 1. 무한한 탐험을 위한 이중 좌표계와 World Shift
우주는 무한하지만 컴퓨터의 연산 공간은 유한합니다. 씬의 중심부에서 너무 멀어지면 좌표 정밀도가 떨어져 화면이 심하게 떨리는(Jittering) 현상이 발생합니다. 
이를 해결하기 위해 우주 전체의 **절대 위치를 나타내는 정수형 청크(Chunk) 인덱스**와 **해당 청크 내부의 실수형 로컬 좌표**를 분리하는 부동 원점(Floating Origin) 아키텍처를 도입했습니다. 탐험가가 일정 영역을 벗어나면 카메라와 주변 환경을 유니티 씬의 원점(0,0,0)으로 강제 회귀(World Shift)시켜, 우주 끝까지 날아가도 언제나 최고 수준의 물리 연산과 렌더링 정밀도를 유지합니다.

### 2. 3차원 공간 분할과 차분 동기화 (Delta Update)
수많은 유저와 천체의 움직임을 브라우저에서 모두 연산하는 것은 불가능합니다. 
이를 해결하기 위해 우주를 3D 그리드 섹터로 분할하고, 플레이어의 시야(Core 및 Buffer 영역)를 실시간으로 계산합니다. **새로 진입한 섹터의 데이터만 구독(Subscribe)하고, 시야에서 완전히 멀어진 섹터는 즉각적으로 구독 해제 및 메모리에서 파괴**하는 차분 갱신 로직을 구현하여 네트워크 트래픽과 가비지 컬렉터(GC) 부하를 획기적으로 낮췄습니다.

### 3. 수학이 만들어내는 우주: 결정론적 절차적 생성
무한한 우주의 모든 별을 데이터베이스에 저장한다면 막대한 서버 비용과 지연이 발생합니다. 
대신, 3차원 청크 좌표 자체를 고유한 해시(Hash) 시드(Seed)로 변환하는 **결정론적 절차적 생성(PRNG)** 알고리즘을 도입했습니다. DB 조회 없이도, 특정 좌표에 도달한 모든 유저에게 수학적으로 완벽히 동일한 종류, 색상, 개수의 무작위 천체를 실시간으로 렌더링하여 일관된 우주를 공유합니다.

### 4. 크로스 플랫폼 네트워크 어댑터
웹 브라우저의 샌드박스 보안 환경에서도 매끄러운 실시간 통신을 보장하기 위해 자체적인 통신 어댑터 패턴을 설계했습니다. 
유니티의 C# 환경과 네이티브 JavaScript WebSocket을 브릿지(`jslib`)로 완벽하게 연결하고, 데이터 직렬화(Serialization) 불일치 문제를 해결하여 서버 물리 엔진의 연산 결과를 지연 없이 클라이언트로 동기화합니다.
